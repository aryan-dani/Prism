prism_kb - enterprise memory

  • One collection for all five domains - not five vector DBs
  • ~519 chunks + BM25 sidecar, fused with Reciprocal Rank Fusion
  • Cross-tags via boolean domain_* flags (warranty lives in Support and Legal)
  • source_priority at ingest: official PDF = 100, Assist HTML = 10
  • Role flags role_* are metadata, not a prompt instruction
  • Agnostic retrieve is still role-filtered, so votes cannot leak a hidden domain

prism_uploads - session only

  • Separate collection, always filtered by session_id
  • PDF / DOCX / TXT / HTML through the same extract.py as the KB
  • Never mixed into prism_kb - a leaked upload cannot poison search
  • Purged on session delete, on file remove, and by a 24h TTL sweep
  • When the user points at the file, Meridian policy_math is skipped
  • Point-at-file is explicit: an attached PDF does not silently hijack every turn

One Ollama call per answer

  • Generator: qwen2.5:7b-instruct Q4 → CanonicalAnswer JSON
  • Embed: nomic-embed-text for both index and query (~274 MB)
  • Titles: qwen2.5:3b with keep-alive 0 - unloads after naming the chat
  • Citations must be ⊆ retrieved source_urls; extras are stripped
  • No router LLM. No second call to "pretty-print JSON"
  • One generation call per answer. Reformats never touch Ollama again

Five renderers, ₹0 reformats

  • Prose · JSON · XML · Excel (.xlsx via openpyxl) · draft email
  • Reformats replay stored last_answer - gates 4-7 never run again
  • RBAC is a Chroma where clause, not a hidden chip in the UI
  • Auth: bcrypt hashes + opaque Bearer tokens in SQLite
  • Peak generation VRAM 5143 MB of an 8151 MiB laptop budget
  • Excel is a file download, not a screenshot of a table in chat

RBAC7 / 10

Innovation pitch

More than a chatbot with a vector DB

Bring your own document

PDF / DOCX / TXT mid-chat into prism_uploads. Point at the file and Meridian policy_math is skipped, so a fake INR table cannot override the user's own policy. Purged on delete and 24h TTL: a privacy story, not a limitation. The file never mixes into prism_kb.

CanonicalAnswer → five formats

Prose, JSON, XML, Excel, email from one stored object. Reformats never re-ask the 7B and never re-retrieve. The JSON on the right is the same Orion metro per-diem (INR 3,250), not a second generation. Click JSON / XML / Excel / Email in the bar: same object, five skins.

EPA water callout

Leak / drip / running-toilet Support answers get labeled liters/day from WaterSense figures: the same "math in code, not in the prompt" pattern as leave carry-forward and INR bands. A dripping faucet is not a 7B guess at gallons. The label is computed, then attached to the CanonicalAnswer.

Voice + cited prompts

Mic + speak in Chrome/Edge. Every reply shows retrieved source URLs and a workflow id that maps 1:1 onto docs/prompts.md. The jury can audit what was actually prompted, including the refuse and policy_math short-circuits that never call the 7B.
